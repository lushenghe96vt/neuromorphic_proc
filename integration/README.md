# Integration Workspace

Team 5 owns the top-level integration, but every team contributes and reviews its connections here.

- `rtl/`: top-level wrapper and block instances
- `tb/`: cross-block and full-system tests
- `scripts/`: full-chip simulation, synthesis, and implementation flows
- `constraints/`: top-level clocks, I/O, power, and timing constraints
- `reports/`: integration, STA, DRC, LVS, PEX, and final results

The integration branch must use released block versions and record the commit or tag used for each block.
